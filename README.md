## Kullanım

Her proje kendi klasörü altında bağımsız bir Flutter uygulaması olarak yapılandırılmıştır. Çalıştırmak istediğiniz projenin klasörüne girip bağımlılıkları yüklemeniz yeterlidir:

```bash
git clone https://github.com/bilalefe/flutter.git
cd flutter/qr-scanner
flutter pub get
flutter run
```
